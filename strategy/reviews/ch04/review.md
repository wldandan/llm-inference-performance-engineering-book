# Chapter Review

## 总体评价

第 4 章从课程已经跑通的真实 vLLM 单实例出发，再按需加入 Router 与 Admission。主课堂案例不再虚构企业平台作为起点；默认契约先检查 `single_instance`，Scale-out 只作职责变化练习。

## 结构问题

新增 Reference System 映射表，逐项区分真机报告直接证明的 Client/API/GPU、架构文档支持的内部逻辑角色，以及当前不可推断的进程边界。企业知识助手与 Agent 重试降为补充案例，Core 主线更贴近前两章。

## 技术与术语问题

Router 负责目标选择，Admission 负责全局准入，Engine Scheduler 负责实例内迭代计划。单实例不强制 Router 与 Admission；多 GPU 细节指向 Advanced 附录，不再错误指向 Chapter 28。

## 内容缺口

第 2 章的客户端流式报告缺少完整启动命令，完整生命周期报告也仍待补，因此当前不能还原版本精确的 vLLM 进程拓扑。正文只画稳定的逻辑职责，并明确这一证据缺口。

## 可删减内容

完整框架对照、虚构性能数据与版本精确的内部类图留在 Advanced 在线材料或真机证据完成后补充，Core 不继续扩展。
