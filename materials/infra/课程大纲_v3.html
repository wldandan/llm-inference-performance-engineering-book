模块一：LLM 推理引擎
8学时理论 + 2学时实验 · 共10学时
回答：第一行代码为什么等了 2 秒？
📖 理论讲次
  • 讲1推理全流程：Prefill/Decode 两阶段，Memory-Bound 本质，TTFT / TPOT / 吞吐量三指标及其矛盾
  • 讲2注意力机制演进：MHA → GQA → MLA，Flash Attention 1/2/3，IO感知算法原理
  • 讲3批处理与调度：Continuous Batching，Chunked Prefill，混合流量优先级调度
  • 讲4推理框架选型：vLLM vs SGLang 架构对比，Radix Attention，什么时候用哪个
🧪 模块实验
推理服务搭建与基准测试
部署 vLLM + SGLang（各一套）； 用 benchmark_serving 测 TTFT / TPOT / 吞吐量； 改变 batch_size 和并发数，观察三指标如何变化； 对比两框架在有无 Prefix Cache 场景下的性能差距
M1 Mac：用 MLX 替代 vLLM 跑小模型，观察同样的指标变化规律
🗄️
模块二：KV Cache 与内存管理
6学时理论 + 2学时实验 · 共8学时
回答：越到后面为什么越慢、并发为什么受限？
📖 理论讲次
  • 讲1KV Cache 原理：为什么需要？内存占用公式推导（层数×头数×维度×序列×Batch），为什么是最大瓶颈
  • 讲2PagedAttention：虚拟页→物理块映射，消除内存碎片，GPU 利用率 40%→75%，源码级解析
  • 讲3Prefix Caching：Radix Attention，System Prompt 只算一次，命中率 90%+，LRU 驱逐策略
延伸：KV Cache 量化压缩（H2O/SnapKV）· 分布式 KV 存储（Mooncake）
🧪 模块实验
KV Cache 内存分析与 Prefix Cache 效果验证
手动计算不同配置下的 KV Cache 内存占用； 测试 System Prompt（500 token）开启/关闭 Prefix Cache 的吞吐量差距； 观察 batch_size 增大时的内存压力与 OOM 临界点
核心产出：一张「KV Cache 内存占用计算器」表格，适合生产容量规划
✂️
模块三：模型压缩与高效架构
6学时理论 + 2学时实验 · 共8学时
回答：如何在质量可接受时降低成本？
📖 理论讲次
  • 讲1量化全栈：PTQ vs QAT，FP16→FP8→INT8→INT4，GPTQ / AWQ / GGUF 对比，量化工具链实践
  • 讲2知识蒸馏：教师-学生范式，DeepSeek-R1 蒸馏实践，从蒸馏视角理解 Speculative Decoding 的 Draft Model
  • 讲3加速解码：Speculative Decoding 原理，Medusa，EAGLE-2 动态草稿树，验证比生成便宜的本质
🧪 模块实验
量化效果三维对比实验
对 Qwen2.5-7B 分别做 FP16 / AWQ-INT4 / GGUF-Q4_K_M； 同时测量：推理速度（token/s）、内存占用（GB）、质量（PPL / 答题正确率）； 画三维权衡图，找到自己场景下的最优量化点
M1 Mac：直接用 llama.cpp GGUF + MLX，对比两种方案
🏗️
模块四：分布式训练基础
8学时理论 + 2学时实验 · 共10学时
回答：7B / 70B 模型是怎么训出来的？
📖 理论讲次
  • 讲1数据并行：DDP / FSDP / ZeRO-1/2/3，Ring-AllReduce 通信，通信计算重叠（Overlap）
  • 讲2模型并行：Tensor Parallelism 列/行并行，Pipeline Parallelism 气泡率，3D 并行（DP+TP+PP）选型
  • 讲3训练内存优化：混合精度 BF16，梯度检查点，Flash Attention in 训练，ZeRO-3 优化器分片
  • 讲4工程实践：Checkpoint 策略，Loss Spike 排查，弹性训练，Megatron-LM vs DeepSpeed 框架对比
🧪 模块实验
分布式训练配置对比实验
跑小型 GPT-2：FP32 基准 / BF16 混合精度 / 梯度检查点； 对比吞吐量（tokens/s）和显存峰值（GB）； ZeRO 三阶段显存节省理论推导 + 可视化； 计算「训练 7B 模型需要几张 A100」
M1 Mac：CPU 模式跑缩小版，BF16 vs FP32 对比依然有意义

模块五：分布式推理与平台工程
6学时理论 + 2学时实验 · 共8学时
回答：1000 个工程师同时用，怎么扛？
📖 理论讲次
  • 讲1本地与边缘推理：Apple Silicon 统一内存架构，MLX 框架，llama.cpp GGUF 实践，云端 vs 本地成本决策
  • 讲2分布式推理：PD 分离架构（Splitwise/Distserve/Mooncake），Expert Parallelism（MoE 推理），多GPU配置选型
  • 讲3AI 平台工程：K8s 推理部署，DCGM + Prometheus 监控，负载均衡，成本优化，OOM 故障排查
🧪 模块实验
本地推理实战 + TCO 成本分析
在 M1/M2 Mac 上用 MLX 运行 Qwen2.5-7B-4bit，测 token/s 和内存； 与 AutoDL A100 同模型对比速度和成本； 计算「服务 1000 个日活用户」的云端 vs 本地年成本
核心产出：一份实际的 TCO 对比分析表，直接用于选型决策
