# 模块三：不同场景下的性能优化策略

**学时**：10学时（5讲 × 2学时）  
**定位**：掌握在不同业务场景下选择正确优化策略的判断力

---

## 本模块教什么

本模块回答一个问题：**同一个模型、同一套硬件，为什么不同业务场景的优化策略完全不同？**

从五个典型场景系统拆解：

| 讲次 | 主题 | 核心场景 | 优化杠杆 |
|------|------|---------|---------|
| 讲1 | 高吞吐场景优化 | 离线批处理（数据标注/评测） | 大Batch + FP8量化 + 异步Pipeline |
| 讲2 | 低延迟场景优化 | 实时对话/代码补全 | 小Batch + Speculative Decoding + 优先级调度 |
| 讲3 | 长文本场景优化 | 1M+ Token文档分析 | Chunked Prefill + Ring Attention + MInference |
| 讲4 | 混合流量场景优化 | 多种请求类型并发 | 优先级队列 + Chunked Prefill调度 + SLA分级 |
| 讲5 | 多模态与边缘推理 | 端侧部署/视觉理解 | 视觉Token压缩 + llama.cpp GGUF + MLX |

---

## 核心直觉（直觉类比总结）

| 技术场景 | 类比 | 优化本质 |
|---------|------|---------|
| 高吞吐批处理 | 工厂流水线 vs 手工作坊 | 规模化换单位成本 |
| 低延迟对话 | 急诊室优先级分诊 | 关键路径缩短 + 抢占调度 |
| 长文本处理 | 整理一本百科全书 | 分块并行 + 稀疏注意力 |
| 混合流量调度 | 急救室+普通门诊同时运行 | 优先级分级 + 动态调度 |
| 多模态/边缘 | 翻译官+速记员协同 | 跨模态Token压缩 + 量化部署 |

## 场景选型速查

```
业务类型 → 优化策略
├── 离线批处理（数据标注/评测/分析）
│   └── 大Batch(64+) + FP8 + 异步流水线 → 最大吞吐
├── 实时对话（<100ms TTFT）
│   └── 小Batch + 投机解码 + 优先级队列 → 最低延迟
├── 长文本（>32K Token）
│   └── Chunked Prefill + Ring Attention → 突破内存上限
├── 混合流量（短对话 + 长文档并发）
│   └── 优先级队列 + Chunked Prefill → 短请求不被长请求阻塞
└── 边缘/移动端
    └── GGUF量化 + llama.cpp / MLX → 端侧可部署
```

**必读论文（按优先级）**

3. MInference (Jiang et al., 2024) — 长文本稀疏注意力

5. Splitwise (Patel et al., 2023) — 延迟/吞吐场景分离
6. LLaVA-UHD / FastV (2024) — 视觉Token压缩
