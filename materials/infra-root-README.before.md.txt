# 课程 02：AI Infra 关键技术与实践

系统广度课：理解硬件、训练、模型压缩、推理引擎与平台怎样支撑模型服务。课程编号与本目录一致，03是AI Native/AET工程方法课，不再沿用旧总览里对调的逻辑编号。

## 在课程体系中的位置

平台系统方向：**02 → 04**。02交付系统认识、训练/推理实验与部署分析；[04推理性能工程](../04%20LLM%20推理性能工程实战/README.md)进一步训练固定负载、可信基线、请求级诊断、优化对照和性能回归。

02不是所有Agent学员的必修前置。[01 Agent三天实训](../01%20AI%20Agent关键技术与实践/README.md)可以先使用已经准备好的模型服务；应用工程师需要平台知识时，再选修本课相关模块。04也不要求完整修完02，可按任务补足推理与系统知识。

## 当前课程与材料

以[课程设计v2](课程设计_v2_2026-06-08.md)为主：58学时，面向有Python、深度学习和Linux基础的学员。按硬件→训练/压缩→推理→平台展开；本轮不重排原有模块，也不把58学时换算为三天。

| 材料 | 内容与使用方式 |

| [硬件基础与性能分析](01_硬件基础与性能分析/README.md) | GPU、内存、互联与性能分析基础 |

| [模型压缩与高效架构](03_模型压缩与高效架构/README.md) | 量化、蒸馏、高效注意力与稀疏化 |

## 与04的边界

02讲清机制、架构和部署：为什么需要KV Cache、调度如何工作、怎么选择并部署引擎。04使用这些机制解释实际瓶颈，重点是负载设计、误差控制、请求级证据、收益与回归，不重复讲一遍框架使用。

01的Agent项目可作为本课模型服务的消费者；[03 AI Native / AET](../03%20AI%20Native的软件工程方法与实践/README.md)负责规范研发过程，不替代本课的训练或推理运行系统。
