# 新建实验简化（2026-09-25）

## 需求 /sm

用户不应先填写几十个参数才能做第一次实验。默认只需确认服务、填写真实模型名称、选择数据即可开始小规模试跑；现有专业配置保留但按需展开。

## 方案与边界

- 仅修改静态页面、交互、样式和测试，不改变 ExperimentSpec、后端接口、执行器或模型服务。
- 默认 Ollama 地址，模型名称由用户填写；提供 vLLM 和自定义入口。只改配置，不自动发现/预检/调用模型。
- 默认五条明确标注的中文示例请求，可导入 JSONL；它们用于发送真实请求，不是协议替身或业务容量证据。
- 快速试跑：5 条测量、并发 1、0 预热、1 次、最大输出 256。基线测量：50 条测量、1 预热、其余同上。显式选择预设才调整关联预算；数据显示样本级输出上限的真实影响。
- 服务地址保留可编辑；实验名称自动提供。连接信息、流量生成、质量目标、安全观测分组折叠；完整 JSON 可直接导入或展开粘贴。
- 导入、克隆和折叠保留所有原配置，显示自定义状态；不将高级配置默默恢复为快捷预设。
- JSON 展开不做强制表单校验。未应用的 JSON 不被表单同步、预设、载入或文件导入覆盖；必须先应用。
- 用户开始前能看到实际请求预算、并发、流式状态、质量状态和未采集资源提示。只有明确点击预检或启动才调用模型。
