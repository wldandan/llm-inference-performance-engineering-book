- 所有 endpoint 字段归入“01 连接模型”，无重复控件：名称/地址直接显示，密钥变量名、上下文长度、环境声明置于卡片内可选设置；保留原提示、值、字段名及完整 JSON 契约。
- 原“实验名称与连接信息”改为“实验信息”，只保留实验名称、备注及实验模板入口。
- “连接模型”按钮始终可见，复用有界预检与独立确认：明确模型/地址、最多 2 次生成、16 输出 tokens；取消或编辑配置不发请求，不启动实验。
- 只读当前 endpoint，试连不依赖数据集、负载、质量配置；未应用的 JSON 需先应用，非法连接字段在卡片中显示错误并可定位。
- 显示检测中、成功或未通过；仅 ready=true 表示成功，HTTP 200 不足以证明就绪；技术详情折叠。
- 检测期间防重复提交，成功/失败后恢复按钮；改连接信息或导入不同连接后旧结果失效，异步旧结果不得覆盖新配置；普通实验预设不改变连接时保留结果。
- 维持原实验提交语义和预算，不改后端，不连接真实模型用于开发验证。
