# V0.1 验收标准与开发计划

用户批准：通用推理优化工作台，EvalScope 底座，F01—F14；只主动实验和优化建议。

## 功能验收（/sm）

| Feature | 可验证行为 | 失败/边界测试 |
| --- | --- | --- |
| F01 目标 | 在线/离线目标、延迟/吞吐/质量约束可保存并逐项判定 | 缺指标为 unknown；不把 reports/hour 当 requests/s |
| F02 服务 | 获取模型列表，分别验证同步与流式真实生成，保存用户声明环境与观测来源 | 401/404/超时、无 usage、无终止原因、上下文未知 |
| F03 数据 | 导入 JSONL 样本，版本指纹、Prompt 哈希、字符/可用 tokenizer token 长度、重复/前缀与类别画像 | 空集、重复 ID、非法参数、超长输入、路径/字段注入 |
| F04 流量 | 固定并发/到达速率、种子、按指定比例混合，展示实际组成和实际发出负载 | 非正数/非有限数、未知类别、并发越界；不合并独立请求 |
| F05 基线 | 实验状态、完整快照、预热标记、缓存条件、重复运行、原始逐请求记录 | 启动失败/部分失败/中断恢复、不覆盖历史 |
| F06 扫描 | 独立扫描并发或 rate，逐点记录，找出已测达标区间 | 某点失败不伪装成功；不同时静默改变两个变量 |
| F07 指标 | 全窗口吞吐、成功率、时延分位数、样本量、按类别拆分、指标定义 | 非流式 TTFT/TPOT 不可用；chunk 不等于 token；未知计数不当 0 |
| F08 观测 | 实验期间按配置采集 Prometheus；保留标签、单位、时间、缺失/错误原因 | 名称不匹配/认证失败/重置/多设备；跨机器时间不能直接相减 |
| F09 质量 | 业务规则/JSON 格式/必需字段/关键词/人工标签，截断检测、质量状态与覆盖率 | 未评估不算通过；人工标签只匹配本次 request_id |
| F10 比较 | 数据/生成/质量/负载条件对齐后比较候选模型与配置，展示差异和限制 | 不兼容实验不排名；中断或质量不足不能胜出 |
| F11 诊断 | 每条诊断有证据、适用条件、缺失信息，支持数据不足 | 不凭 TTFT 或 KV 使用率单指标推断根因 |
| F12 复测 | 建议包括调整项/风险/验证方法，绑定基线和复测，判定有效/无效/不足 | 变更混杂、质量下降或未知时不能宣称改善 |
| F13 报告 | 本地 JSON/Markdown/HTML 报告与原始记录可追溯，默认分享不含原文/密钥 | HTML 注入、任意文件读取、敏感配置泄露 |
| F14 保护 | 请求、并发、时长、输出 token 预算、超时、取消、秘密环境变量 | 停止后不再发新请求、在途请求标记中断、无服务端修改 |

## 发布门槛

- /arch、/ui 审查后编码；/rev 在最终 QA 前检查代码与安全。
- 单元覆盖率 >80%，集成覆盖率 >60%；不足时补充真实行为测试，不靠排除业务代码降低门槛。
- 可通过文档命令在独立环境安装、启动、运行本地示例；示例明确不是模型性能。
- 不依赖 spike 的未跟踪文件；不读取不可信 pickle；不记录密钥。
- F01—F14 逐项映射到代码、测试和实际运行记录。
- 真实 Ascend/模型效果不属于本机协议验证结论，必须保留限制说明。

最终验收结果和逐项代码/测试映射见 [validation.md](../validation.md)。全部 486 项测试通过，单元覆盖率 89%、集成 79%；独立安装与本地协议运行通过，真实硬件性能未验证。
