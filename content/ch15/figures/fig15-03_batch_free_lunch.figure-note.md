# 图15-3 批量的免费区间与三处边界

- 来源段落：15.4
- 阅读顺序：先看上栏那条涨得很陡的吞吐曲线，再看下栏几乎不动的 TPOT，最后看右侧三处边界
- 关键结论：带宽受限区间内加批量近乎免费；越过交叉批量 153 之后，再加就真的变慢
- 表达边界：两条曲线按参考卡（带宽 1000 GB/s、分界点 153，与 A100 相同）和 512 token 上下文算，长上下文下会明显不同（见图15-4）。灰色区从 153 起，是忽略 KV 读取时的交叉批量；把 512 token 的 KV 算进去，交叉批量其实要到五六百。它们只算搬运不算算力，所以 153 右侧那段灰色区域是模型自己失效的地方，不是预测。换卡或换位宽，交叉批量都会移动
