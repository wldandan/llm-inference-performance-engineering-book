# traffic-trace-sample.csv

**合成设定，不是真实流量。** 四小时、30 秒一个采样点，两层结构：

- 小时级的增长与回落：从 450 涨到约 1150 再回落
- 一次突发：第 2.5 小时处 90 秒内翻到三倍

两层是刻意分开的，因为 27.5 那张表要区分的正是这两类变化。模拟器里的 reactive
策略代表的是不可预测的那一类小时级增长（可预测的日内波峰该用定时扩缩容提前拉起），
突发那一层只能靠准入控制和预留余量。用 `compare` 跑这段轨迹，`admission-only` 在突发
那一段上的表现会好于纯反应式弹性。

用在自己的服务上时，换成一段真实的日内流量再跑。
