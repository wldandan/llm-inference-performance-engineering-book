# 图 0-1 制作说明：朴素的四步生成循环

- 来源段落：第 0 章“0.2 模型是一摞参数，回答是一个循环”中的四步循环与“这个循环有一处明显的浪费”两段。
- 核心问题：写一段回答，机器里重复发生了什么？
- 阅读顺序：先读上方四张卡片和回流虚线，再读下方逐圈列出的输入内容，注意橙色框标出的重复部分。
- 关键结论：一段回答要转很多圈；朴素做法每一圈都在重复处理没变过的历史。
- 边界：右上角标明“朴素模型”，真实做法在 0.3 交代；只画四框，不画 Tokenizer、Embedding、LM Head 等七步管线（那是图 3-1 的粒度）；不出现 KV Cache、Prefill、Decode、Attention、张量形状。
