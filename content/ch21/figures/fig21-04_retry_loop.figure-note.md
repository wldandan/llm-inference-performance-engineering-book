# 图21-4 重试把 4% 的失败推成 73%

- 来源段落：21.5、21.9 案例一
- 阅读顺序：先从上往下读左边那四行，注意第 0 轮的放大系数只有 1.04，再看右边那个环怎么把上一轮的结果变成下一轮的输入，最后看底部那句把 73% 和 71% 连起来的话
- 关键结论：第 0 轮那 4% 的额外流量看起来完全无害，而它正是把 p 从 4% 推到 15% 的那一下
- 表达边界：四轮的失败率是合成设定，放大系数和可用性由 code/ch21/overload_drill.py 算出；放大系数按各次独立失败的精确式算，速记的 1 + p·r 是它的上界；单看一轮的式子会低估雪崩，因为它漏掉的是 p 被负载一轮轮推高的回路，这张表走的正是这个回路
