## 这份附录要回答什么

1. 张量并行、流水并行和数据并行各自切的是什么，为什么推理侧最常用的是张量并行。
2. 张量并行把一层切成 N 份之后，每一步要同步几次、同步多少字节，以及这笔通信量怎么估。
3. NCCL 的 AllReduce 在 NVLink 和 PCIe 上的差别有多大，为什么拓扑决定了并行度能开到多少。
4. 扩展效率怎么测：固定什么、变什么、用哪个指标，以及为什么不能用吞吐的绝对值直接比。
5. 为什么两卡的吞吐通常达不到单卡的两倍，缺的那部分落在通信、负载不均还是显存碎片上。

## 与正文的接口

- 第 27 章讲多副本和 Autoscaling，讲的是“同一个模型起几份”；附录 C 讲的是“一份模型摊在几张卡上”。两件事都叫扩展，容易混，附录开头要先把这两个词分开。
- 第 15、16 章的搬运下限和容量上限都是按单卡写的。附录 C 要说明这两个式子在张量并行下怎么改：分子按切分数摊薄，但要加上同步的通信时间。
- 第 26 章算卡数时用的是稳态式子，附录 C 要给出并行度对每卡有效吞吐的折扣，否则卡数会算少。
